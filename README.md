# customer-churn-prediction
Machine learning project to predict customer churn using classification models.

## Project Overview
This project predicts whether a telecom customer will churn using machine learning techniques.

## Dataset
Telco Customer Churn dataset with 7043 customers and 21 features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Logistic Regression
- Random Forest

## Key Insights
- Customers with shorter tenure are more likely to churn
- Higher monthly charges increase churn probability
- Long-term contracts reduce churn
- Fiber optic internet customers show higher churn behaviour

## Model Performance
Random Forest and Logistic Regression models were trained and evaluated using accuracy, precision, recall and F1-score.

## Conclusion
Customer tenure, monthly charges and contract type are strong indicators of churn behaviour.
